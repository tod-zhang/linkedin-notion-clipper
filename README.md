# LinkedIn → Notion 剪藏

一个 Chrome 扩展：在 LinkedIn 上看到值得保存的动态或文章，点一下就把**文字和图片**一起存进你的 Notion 数据库。

- **动态**：每条动态右上角「···」左边多出一个书签按钮，点一下即剪藏
- **文章**（`linkedin.com/pulse/…`）：左下角出现「剪藏文章到 Notion」按钮
- **工具栏图标**：剪藏当前文章，或屏幕上最显眼的那条动态
- **图片永久保存**：图片下载后上传到 Notion（LinkedIn 的图片链接会过期，所以不直接引用），自动选用最高清的版本
- 保留加粗、斜体、链接、#话题标签、段落；文章还保留标题层级、列表、引用、分割线
- 转发的动态会保留原帖（以引用块显示）；链接卡片保存为书签；视频保存封面；PDF 文档轮播保存已加载的页
- 自动填写数据库属性：标题、原帖链接、作者、发布时间、类型（动态/文章）、图片
- 重复检测：同一条动态再次剪藏时会提示「已剪藏过」，也可以「再存一份」

## 安装（约 3 分钟）

### 1. 加载扩展

1. 打开 `chrome://extensions`（Edge 为 `edge://extensions`，其他 Chromium 内核浏览器同理）
2. 打开右上角的 **开发者模式**
3. 点 **加载已解压的扩展程序**，选择本文件夹（包含 `manifest.json` 的那一层）
4. 建议把扩展图标固定到工具栏

### 2. 创建 Notion 集成

1. 打开 [notion.so/profile/integrations](https://www.notion.so/profile/integrations) → **新建集成**
2. 类型选 **内部（Internal）**，选择你的工作区
3. 能力（Capabilities）勾选：**读取内容、更新内容、插入内容**
4. 保存后复制 **Internal Integration Secret**（以 `ntn_` 开头）

### 3. 给数据库授权

在 Notion 里打开要存放剪藏的数据库（表格），点右上角 **···** → **连接（Connections）** → 搜索并添加刚才的集成。

### 4. 填写设置

安装后设置页会自动打开（也可以右键扩展图标 → 选项）：

1. 粘贴集成令牌 → **连接**（会显示你的工作区名称）
2. 在「选择数据库」下拉框里选中你的数据库（列表里只有已连接此集成的数据库；也可以展开「或者粘贴数据库链接」）
3. 检查「字段对应」，没有合适属性时点 **一键添加推荐属性**
4. 回到 LinkedIn，**刷新页面**，开始剪藏

## 多设备同步

设置保存在浏览器的同步存储（`chrome.storage.sync`）里，只需在一台设备上填一次：

1. 每台设备登录同一个浏览器账号并开启扩展同步：
   - Chrome：登录同一个 Google 账号，**设置 → 同步 → 管理同步内容** 里开启「扩展程序」
   - Edge：登录同一个 Microsoft 账号，**设置 → 个人资料 → 同步** 里开启「扩展」
2. 把本文件夹复制到其他设备（网盘、U 盘、git 均可），同样用「加载已解压的扩展程序」加载
3. 打开扩展设置页，令牌、数据库和字段对应会自动出现

扩展的 `manifest.json` 里有固定的 `key`（就是 Chrome 应用商店为本扩展分配的公钥），所以无论文件夹放在哪里、还是从商店安装，扩展 ID 都是 `ngpompbphnmpeelppaaincipnboloeag`，各设备才能共用同一份同步设置。请不要删除这个 `key`。

> 不用 Chrome 同步的浏览器（部分 Chromium 衍生浏览器）里，设置只会保存在本机，需要在该设备上填一次令牌、选一次数据库。

**从 1.0 升级**：1.1 起扩展 ID 固定了，旧版本的设置不会自动带过来。请在 `chrome://extensions` 里移除旧的扩展，重新「加载已解压的扩展程序」，再在设置页填一次令牌、选一次数据库。

## 推荐的数据库结构

「一键添加推荐属性」会创建下面这些（已有同类属性的会自动识别，中英文名都可以）：

| 属性 | 类型 | 内容 |
| --- | --- | --- |
| （标题） | 标题 | 动态第一行 / 文章标题 |
| 链接 | 网址 | 原帖链接，用于重复检测 |
| 作者 | 文本 | 作者名（带主页链接） |
| 发布时间 | 日期 | 动态发布时间 / 文章日期 |
| 类型 | 单选 | 动态 / 文章 |
| 图片 | 文件和媒体 | 所有图片（适合画廊视图） |
| 剪藏时间 | 创建时间 | Notion 自动填写 |

每个页面都带 LinkedIn 图标。页面正文依次是：作者·时间·原帖链接 → 正文 → 图片。默认不设封面，需要的话可在设置中开启「用第一张图片作为页面封面」。

## 已知限制

- **视频**只保存封面图，视频本身请在原帖观看
- **PDF 文档轮播**只保存页面上已加载的页（通常前几页）
- **图片大小**：Notion 免费版单文件上限 5 MB，扩展会自动选用不超过 5 MB 的最大尺寸；极少数超大动图（如 10 MB 的 GIF 广告）在免费版上会改为外链，外链日后可能失效
- **纯图片无文字的动态**在信息流中可能拿不到原帖链接（打开该动态的详情页再剪藏即可）
- **群组动态**的作者可能留空
- LinkedIn 经常改版。扩展只依赖较稳定的页面结构（`role`、`data-testid`、`componentkey`、图片地址格式），不依赖会变化的样式类名；如果某天按钮不见了，多半是 LinkedIn 改版，需要更新 `src/content/extract.js` 顶部的选择器

## 上架 Chrome 应用商店

```bash
npm run package
```

会生成 `dist/linkedin-notion-clipper-<版本>.zip`，并自动去掉 `manifest.json` 里的 `key`（应用商店会自己分配扩展 ID，带 `key` 上传会被拒绝）。

**只给自己多设备用**：推荐上架到 [Edge 加载项商店](https://partner.microsoft.com/dashboard/microsoftedge)，可见性选「隐藏（Hidden）」——免费、搜索不到，只有拿到链接的人能装；Edge 同步会把它装到你登录同一账号的其他设备上，之后更新也会自动推送。Chrome 应用商店则可选「私有（Private）」并只把自己加为受信任测试人员（需一次性 5 美元注册费）。两者每次更新都要等审核。换成商店版后，请删掉本地加载的版本（否则每条动态会出现两个按钮），并在商店版的设置页再填一次令牌。

- **开发版和商店版共用 ID**：`manifest.json` 里的 `key` 已经换成商店分配的公钥（开发者后台「文件包」页 →「查看公钥」），本地加载的版本和商店版 ID 相同，同步的设置也通用。
- **必须准备**：隐私政策网址，以及后台「隐私权」页的数据用途声明（本扩展处理：身份验证信息 = Notion 令牌；网站内容 = 剪藏的动态/文章）。每个权限都要写用途说明。
- **名称与商标**：名字里的 LinkedIn、Notion 是他人商标，建议用「… for LinkedIn」这类说明性写法，商店图标不要使用它们的 Logo。
- **代码是公开的**：任何人都能解压商店版查看代码，所以代码里不能放任何密钥。目前没有；以后若加「用 Notion 登录」（OAuth），客户端密钥必须放在自己的服务器上，不能写进扩展。

## 隐私

完整的隐私政策见 [PRIVACY.md](PRIVACY.md)。

- Notion 令牌和设置保存在浏览器的同步存储（`chrome.storage.sync`）中，只通过你自己的 Chrome 同步传到你登录的其他设备，不会发送到别处
- 扩展只和两个地方通信：`api.notion.com`（写入你的数据库）和 LinkedIn 图片 CDN `*.licdn.com`（下载图片）
- 不收集任何数据，没有统计代码

## 开发

```
manifest.json              MV3 清单
src/content/extract.js     从 LinkedIn 页面提取内容（纯 DOM，可注入页面单独测试）
src/content/content.js     页面按钮、提示条、与后台通信
src/background.js          Service Worker：接收剪藏请求
src/lib/clip.js            下载图片 → 上传 Notion → 建页面 的流程
src/lib/blocks.js          剪藏内容 → Notion 块和属性（处理 2000 字 / 100 块等限制）
src/lib/notion.js          Notion API 客户端（API 版本 2025-09-03，限速与 429 重试）
src/lib/mapping.js         字段与数据库属性的自动匹配
src/lib/settings.js        设置读写（Chrome 同步存储）
src/lib/images.js          图片下载、格式识别、尺寸选择
src/options/               设置页
test/                      单元测试 + 严格校验 Notion 请求限制的模拟 API
scripts/make_icons.py      生成图标（需要 Pillow）
```

```bash
npm test
```

修改代码后，在 `chrome://extensions` 点扩展卡片上的刷新按钮，再刷新 LinkedIn 页面。
